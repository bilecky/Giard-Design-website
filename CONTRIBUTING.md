# Contributing

Thanks for your interest! This is a training project built as a static site. While external contributions aren’t expected, suggestions and small improvements are welcome.

## Code style
- HTML: semantic where possible
- CSS: keep custom styles in `main.css`; prefer Tailwind utility classes for layout/states
- JS: vanilla, no frameworks; keep behavior in `main.js`

## Commit messages
- Use clear, descriptive messages (e.g., `feat: add lightbox to gallery`, `fix: close mobile menu on item click`).

## Issues and PRs
- Open an issue describing the change/bug.
- For PRs, keep edits focused and small; include before/after screenshots/gifs when UI changes are involved.

## Assets
- Only include assets you have rights to use.
- Update `alt` text and filenames to match new content.
